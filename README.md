### Project Description
[*Naturally Useless** is a fun survival-training game where animals are trained to handle the **worst-case scenarios** and become better at survival. The goal is to improve their skills, achieve **good placement**, and ultimately reach the **highest LPA (Life Per Animal)*]

### The Problem (that doesn't exist)
[teaching animals their skills even world collaps]

### The Solution (that nobody asked for)
[By giving difficult training higher than US army training]
